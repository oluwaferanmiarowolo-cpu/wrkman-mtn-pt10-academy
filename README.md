# Wrkman MTN PT10 Installer Academy

A responsive, blue-and-white installer training course for MTN PT10 ODU installations.

## Features
- Eight sequential training modules with completion gating.
- Progress saved in the browser using local storage.
- Twenty-question multiple-choice assessment.
- Five marks per question, automatic scoring, answer review and 70% pass mark.
- Responsive layout for phones, tablets and desktops.

## Deploy with GitHub Pages
1. Open Settings → Pages in this repository.
2. Under Build and deployment, set Source to GitHub Actions.
3. The workflow in .github/workflows/deploy.yml deploys the site whenever changes are pushed to main.
4. Check the Actions tab for the deployment run and open the published Pages URL.

## Training note
This is a training aid. Installers must follow the latest MTN and equipment-manufacturer instructions for the exact hardware revision. In particular, verify port labels and use only the approved power supply. The course includes the demonstrated connection checks: UPS LAN to router WAN, ODU data link to UPS PoE, and router power from the approved 12V UPS output only.
